# 安大通 for macOS

基于[OpenAHU/AHUTong](https://github.com/OpenAHU/AHUTong)项目移植的macOS端第三方安徽大学教务App
<center>

![ahu-logo](/ahu-logo-128px.png)

</center>

## 功能
- 查看课程表
- 查看校园卡数据，包括余额以及付款码
- 查询成绩
  - 课程名称、学分、分数、绩点
  - 总成绩加权平均分、平均绩点、已修学分
  - 课程按成绩从高到低排序
- 查询考试日期、地点、座位号
- 常用网站入口，如安大官网、教务处、智慧安大等
- 自定义头像、名称（保存在本地）
- 上课前30分钟推送通知

## 特点
- 使用Swift UI + Rust语言，Swift UI主要用于前端构建，Rust提供底层。
- Codex搭配GPT-5.6-Sol开发，同时对部分内容进行人工优化
- 充分采用Apple原生框架，便于针对苹果设备进行开发

## 系统要求
- **macOS 14** 或更新版本
- 使用**Apple Sillicon**的Mac，Intel版Mac不支持
- ***Xcode 16** 或更新版本（开发用）*

## 安装
1. 在```release```页下载相应版本的```AHUTong-xx-arm64.dmg```文件
2. 将文件移动至```应用程序```文件夹（/Users/你的用户名/Applications）
3. macOS 26之前的版本可以通过启动台打开，后续版本通过```cmd+空格```搜索并打开
### 提示“Apple无法验证“安大通”是否包含可能危害Mac安全或泄漏隐私的恶意软件。”
这是由于苹果会自动拦截无证书的软件，不代表本软件有任何危害。如果出现该提示，可以通过以下方式解决：
- **方法一**（右键绕过，最推荐）：按住键盘上的 Contro讠键，用鼠标点按该应用图标，在弹出的菜单中选择“打开”，然后在警告圈口中再次点击“打开”。
- **方法二**（系统设置允许）：打开苹果电脑的 系统设置（或系统偏好设置）>“隐私与安全
性”，向下滚动找到被阻止的软件提示，点击“仍要打开”。
- **方法三**（终端命令）：如果以上方法无效，可以打开“终端”App，输入命令 sudo spctl --master-disable 并回车，输入开机密码后（密码不会显示在屏幕上），再去系统设置中
勾选允许“任何来源”的软件。
